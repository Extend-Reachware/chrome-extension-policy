Privacy Policy

reachware — Sale ID Note Sync browser extension · Last updated: October 7, 2026

This policy describes what data the reachware G — Sale ID Note Sync browser extension (the "Extension"), published by Reachware, collects, where it stores that data, and where it sends it. The Extension is a business integration tool for golf-course staff who use Chronogolf / Lightspeed Golf (LightSpeed G) together with Lightspeed Retail (LightSpeed R).

Purpose

When staff complete a sale for a tee-time reservation, the Extension associates the completed Lightspeed sale with the reservation it pays for, and sends that link (the Sale ID and the reservation's booking reference) to the Reachware backend so the integration can record which sale belongs to which reservation. It also reports whether the sale-link webhook succeeded or failed, along with the time of that report. The Extension collects data only for these integration purposes.

Where the Extension is active

The Extension runs only on pages under chronogolf.ca and chronogolf.com. On those pages it looks at exactly three Chronogolf/Lightspeed API calls made by the page itself:

  • creating a reservation (POST /private_api/reservations) — the response is read;
  • starting a tee-sheet checkout (POST /private_api/clubs/<club>/teesheet_checkout) — the request is read;
  • the sale-completed notification (POST /private_api/cb/lightspeed_sale_completed) — the request is read.

All other network traffic and page content is ignored. The Extension does not run on any other website and does not record browsing history.

Data collected

From the three API calls above, the Extension collects only the following operational identifiers:

  • Booking Reference of a newly created reservation;
  • Club ID of the golf club the reservation or sale belongs to;
  • Round IDs — the identifiers of the tee-time rounds in a reservation and in a checkout;
  • Sale ID of a completed Lightspeed sale.

To match a sale to the right reservation, the Extension also records, locally only:

  • the browser's internal numeric ID of the tab in which the reservation, checkout or sale occurred; and
  • the time each item was captured.

The Extension does not collect customer names, email addresses, phone numbers, reservation notes, prices, payment-card details, or any other content of those API calls. It does not read or store your Chronogolf or Lightspeed login credentials, cookies, or authentication tokens.

Local storage

The Extension uses the browser's local extension storage (chrome.storage.local) on your computer for the short-lived data it needs to match a sale to a reservation. This storage stays on your device. The Extension does not sync it to your browser account, and it is not cloud storage.

All of the Extension's local storage is deleted by the browser when the Extension is uninstalled.

Data transmission

When the Extension has matched a completed sale to a reservation, it sends one HTTPS request to the Reachware backend at https://app.reachware.com/ containing exactly three values:

  • Booking Reference
  • Sale ID
  • Club ID

After the sale-link request reaches a final outcome, a separate HTTPS request to the Reachware status webhook contains the Club ID, Booking Reference, Sale ID, whether the sale-link request failed, and the status-report time. `Has_Error` is false when the sale-link request succeeds and true when it fails. If the sale-link request still fails after three attempts, the same three identifiers are kept in local storage (see "Failed deliveries" above) and sent again later. Round IDs, tab IDs and the activity log are never transmitted. If a sale cannot be matched with certainty, nothing is sent. As with any web request, Reachware's server also receives standard connection information such as your IP address and browser user-agent.

The Extension sends data only to the Reachware backend.

Data sharing

  • Collected data is transmitted only to the Reachware backend, and only to provide the Extension's integration functionality.
  • Data is not sold, and it is not shared with advertisers or third-party advertising networks.
  • The Extension contains no advertising, analytics, or tracking code.

The use of information received by this Extension complies with the Chrome Web Store User Data Policy, including the Limited Use requirements.

Security

Data sent to Reachware is transmitted over HTTPS. Messages passed between the Extension's own components are checked before use, and only the fields listed above are stored or forwarded. Data held in local browser storage is protected by your browser and operating-system account. The Extension does not add its own encryption to it.

Your choices

  • Clear the activity log at any time from the Extension popup.
  • Resend failed deliveries at any time with the "retry now" button in the Extension popup.
  • Uninstall the Extension to stop all collection and delete everything it has stored locally.
  • For questions about data already received by the Reachware backend, including access or deletion requests, contact us at the address below.
